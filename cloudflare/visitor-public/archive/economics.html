Изменить допущения и посмотреть методику

Это редактируемые плановые допущения, не замеры текущей партии. API-ставка должна включать оплачиваемые запросы; дополнительные расходы planner/инфраструктуры в базовом сценарии равны нулю.

Ставка геймдизайнера €30 000 gross/год — условный прокси, не рыночная оценка этой роли. В базовом сценарии на коллекцию из 10 карт: $1,25 API + $0,53875 ввода брифа = $1,78875. На карточку — $0,178875 без промежуточного округления.

Расчёт: новые расходы = N ÷ доля приёмки × API за попытку + округлённое вверх число коллекций N/10 × минуты брифа ÷ 60 × ставка GD. Полная сумма = новые расходы + $2 832,307692. Разница = зарплатная стоимость художника − полная сумма AI. Неполная коллекция оплачивает целый бриф.

Активное время после прототипа: GD = N/300 часов; Junior = 6N, Middle = 3N, Senior = 2N часов в базовом сценарии. Для 10 000 карт: 33,33 часа ввода брифов и соответственно 60 000 / 30 000 / 20 000 часов художника.
